# v1.0.0

First release of a complete order-to-cash workflow on Camunda 8.8, Java 21 and Spring Boot 3.5.

## Highlights

- **One BPMN process for the whole order**: stock check, DMN decision, approval in Tasklist, reservation, invoice,
  payment, shipping, and the unhappy paths (sold out, declined, never paid).
- **Payments via Kafka**, correlated with the order id, deduplicated by payment id and buffered when they arrive early.
- **Dunning in the model**: a non-interrupting reminder timer and an interrupting deadline timer, both with durations
  from the decision table.
- **Compensation**: an unpaid order releases its stock and cancels its invoice before it is cancelled.
- **Transactional outbox** for order events on `order-events`, with `OrderReceived` always first.
- **Tests on every level**: Camunda Process Test with a controlled clock, decision tests per rule, unit tests,
  PostgreSQL integration tests and an end-to-end test with real workers, PostgreSQL, Kafka and Camunda.
- **`docker compose up`** starts Camunda (Zeebe, Operate, Tasklist), Elasticsearch, PostgreSQL, Kafka and the service.
